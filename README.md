## 🚀 Featured Engineering Projects

### 1. ⚖️ Lexdraft: Legal RAG & Automated Contract Drafting Platform
**Capstone / Internship Thesis Project** | **Role:** Team Leader & Core AI Engineer  
**Tech Stack:** `Python` · `Streamlit` · `Google Gemini 1.5 Pro/Flash` · `FAISS` · `Ragas` · `Modular Monolith`  
**Repository:** [github.com/gthinh29/Lexdraft](https://github.com/gthinh29/Lexdraft)

> **Problem**: Legal document drafting and contract validation in Vietnam are error-prone and time-consuming, while generic LLMs struggle with outdated law references, hallucinations, and lack of Vietnamese legal context.

```
┌──────────────────┐     ┌────────────────────────────────────────────────────────┐
│ Vietnamese Laws  │────▶│ Lexdraft AI Core (Modular Monolith)                    │
│ & Legal Articles │     │  ┌───────────────────────┐  ┌───────────────────────┐  │
└──────────────────┘     │  │ Structure-Aware Chunk │  │  FAISS Vector Index   │  │
                         │  │   (Điều/Khoản Parser) │  │  (768-dim Embeddings) │  │
                         │  └───────────┬───────────┘  └───────────┬───────────┘  │
                         │              │                          │              │
                         │              ▼                          ▼              │
┌──────────────────┐     │  ┌──────────────────────────────────────────────────┐  │
│ Service Contract │────▶│  │ Law Validity Checker + Risk Assessment Prompts   │  │
│ (DOCX / Text)    │     │  └──────────────────────────────────────────────────┘  │
└──────────────────┘     └───────────────────────────┬────────────────────────────┘
                                                     ▼
                                      Drafted Contracts / Risk Advisory
```

- **Modular Monolith Architecture**: Structured backend into discrete modules: `drafting`, `risk_assessment`, `chatbot_qa`, và hạ tầng dùng chung `shared`.
- **Structure-Aware Legal Chunking**: Thiết kế bộ phân đoạn ngữ cảnh thông minh bám sát cấu trúc phân cấp Điều/Khoản luật Việt Nam thay vì chunking theo số từ/ký tự ngẫu nhiên, giúp tối ưu độ khớp ngữ nghĩa.
- **Law Validity Checker**: Xây dựng pipeline kiểm tra và phát hiện văn bản luật đã hết hiệu lực pháp lý để ngăn chặn dẫn chiếu sai quy định.
- **Scientific RAG Benchmarking**:
  - Tích hợp framework **Ragas** tự động đánh giá: Faithfulness, Answer Relevance và Context Precision.
  - Thiết kế và kiểm chứng 3 giả thiết khoa học: so sánh A/B với LLM thuần, khảo sát triệt tiêu (ablation study) metadata pháp luật và ngưỡng an toàn từ chối hallucination.

### 2. 🎓 EduChatbot: Intelligent Enterprise Educational Assistant
**Research & University Project** | **Role:** AI & Fine-Tuning Engineer  
**Tech Stack:** `Python` · `Llama 3.1 8B` · `LoRA / QLoRA` · `Java 17 (Spring Boot 3)` · `LangChain4j` · `Qdrant` · `FastAPI`  
**Repository:** [github.com/gthinh29/Educhatbot](https://github.com/gthinh29/Educhatbot) &nbsp;|&nbsp; **Live Demo:** [educhatbot-orcin.vercel.app](https://educhatbot-orcin.vercel.app/)

> **Problem**: University students need verified academic answers across syllabus materials, requiring an empirical study determining optimal trade-offs between RAG and Parameter-Efficient Fine-Tuning (PEFT).

```
   [React Client] ──▶ [Spring Boot 3 Server (Java 17)]
                              │
            ┌─────────────────┴─────────────────┐
            ▼                                   ▼
    [Spring Security + JWT]             [LangChain4j RAG Core]
    (RBAC: Student/Teacher/Admin)      (Qdrant Vector DB + Tika)
            │                                   │
            ▼                                   ▼
    [PostgreSQL Database]             [FastAPI Inference Bridge]
    (Documents & Audit Logs)          (LoRA Fine-Tuned Llama 3.1 8B)
```

- **LLM Fine-Tuning Specialization**: Trực tiếp đảm nhận vai trò **Fine-tune Llama 3.1 8B** sử dụng phương pháp LoRA/QLoRA trên tập dữ liệu giáo trình và tài liệu đào tạo chuyên biệt; tối ưu cấu trúc phản hồi và độ chính xác chuyên môn.
- **Thực nghiệm so sánh RAG vs Fine-Tuning**: Thiết kế pipeline benchmarking độc lập so sánh hiệu năng, độ trễ (latency), tỷ lệ hallucination giữa hai phương pháp RAG và Fine-tuning.
- **Java-Python Microservice Communication**: Tích hợp Spring WebClient kết nối bất đồng bộ giữa backend Java Spring Boot 3 LangChain4j và dịch vụ Python FastAPI phục vụ model LoRA.
- **Enterprise Security & Phân quyền**: Quản lý phân quyền chặt chẽ theo vai trò (`STUDENT`, `TEACHER`, `ADMIN`) qua Spring Security & JWT.

### 3. 🍜 ROS: Real-time Restaurant Ordering & Kitchen Management System
**Full-Cycle Software Engineering Project** | **Role:** Team Leader & Core Backend Engineer  
**Tech Stack:** `Python (FastAPI)` · `SQLAlchemy` · `PostgreSQL` · `Flutter (Dart)` · `WebSockets` · `Docker`  
**Repository:** [github.com/gthinh29/ROS](https://github.com/gthinh29/ROS)

> **Problem**: Traditional restaurant operations suffer from delayed order-to-kitchen handoffs, bill splitting mistakes, and fragmented communication between front-of-house staff, cashier, and kitchen.

```
                           ┌───────────────────────────────┐
                           │         Nginx Gateway         │
                           └───────────────┬───────────────┘
                                           │
                           ┌───────────────▼───────────────┐
                           │      FastAPI Backend Core     │
                           │   (Sync ORM + WebSockets)     │
                           └───────┬───────────────┬───────┘
                                   │               │
        ┌──────────────────────────┴────┐     ┌────┴──────────────────────────┐
        ▼                               ▼     ▼                               ▼
 [Customer Web / App]             [Staff App] [Kitchen Display (KDS)]   [POS / Admin Web]
 (Flutter Web / QR)              (Flutter Mobile) (Flutter Web Realtime) (Flutter Web)
```

- **Team Leadership & System Architecture**: Trưởng nhóm dự án 4 thành viên; trực tiếp thiết kế kiến trúc toàn hệ thống, sơ đồ CSDL (ERD), đặc tả API contracts & giao thức WebSocket thời gian thực, điều phối Git workflow và review mã nguồn.
- **Core Backend Engineering (Personal Contribution)**: Trực tiếp phát triển toàn bộ core backend với **FastAPI**, **SQLAlchemy** (Session / Engine) và **PostgreSQL**; tối ưu hóa luồng nghiệp vụ máy trạng thái bàn ăn (Table State Machine) và chia tách hóa đơn (Split Bill).
- **Real-Time WebSocket Event Bus**: Thiết kế cơ chế WebSocket broadcast kết nối tức thời đơn đặt món từ bàn ăn khách hàng tới màn hình hiển thị tại bếp (KDS) và quầy thu ngân với độ trễ <1s.
- **Cross-Platform Frontend (Team Collaboration)**: Toàn bộ client apps (`customer_web` và `internal_web`) được xây dựng đồng nhất trên nền tảng **Flutter / Dart** bởi các thành viên frontend, giao tiếp với backend qua REST API & WebSockets.
- **Containerization & Deployment**: Đóng gói backend FastAPI, cơ sở dữ liệu PostgreSQL và reverse proxy Nginx bằng **Docker Compose** với healthcheck tự động.
